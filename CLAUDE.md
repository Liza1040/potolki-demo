# CLAUDE.md — potolki-demo

Дополняет корневой `../../CLAUDE.md`. При конфликте приоритет у этого файла.

## Что это

Демо-лендинг для портфолио: квиз по натяжным потолкам, вымышленная компания
«Потолки Первый Метр», Москва. Легенда и возражения — в `BRIEF.md`,
статус и решения — в `NOTES.md`.

## Ниша и тон

Массовый ремонт, не премиум. Человек пришёл из Директа, сравнивает 3–4 сайта,
решает по цене и предсказуемости. Тексты — спокойные и конкретные,
без давления, без «премиум-качества», без восклицательных знаков.

## Правила проекта

- **Тексты живут только в `content/`.** В JSX не должно быть ни одной
  русской строки, кроме `aria-label` и служебных подписей.
- Каждая секция принимает свой кусок контента пропсом:
  `<Hero content={content.hero} />`. Секции не импортируют `content/` сами.
- Все типы контента — в `content/types.ts`, объекты типизируются `satisfies`,
  чтобы не терять литеральные типы.
- Токены темы — CSS-переменные в `globals.css` через `@theme`.
  Цвета в разметке только через них: `bg-brand`, `text-ink`, `bg-cta`.
- Мобильный вид первичен, проверка от 360px, горизонтального скролла нет.
- Всё, что пригодится второй раз (`ui/`, `api/lead`, `analytics/`),
  после сдачи демо переезжает в `kit/`.
